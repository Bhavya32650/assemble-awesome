# Iris Flower Classification using K-Nearest Neighbors (KNN)

## DecodeLabs Industrial Training Kit – Project 2

A modern interactive machine learning web application that classifies Iris flower species using the K-Nearest Neighbors (KNN) algorithm.

The application allows users to adjust flower measurements using sliders and instantly visualize predictions, classification metrics, and confusion matrix results.

---

## Live Features

* Interactive Iris Flower Classification
* Real-Time Prediction
* K-Nearest Neighbors (KNN) Algorithm
* Adjustable K Value
* Feature Visualization
* Scatter Plot Representation
* Confusion Matrix
* Accuracy Metrics
* Precision, Recall and F1 Score
* Responsive User Interface

---

## Machine Learning Workflow

### Input

The user provides:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

### Process

1. Standardize Input Features
2. Calculate Euclidean Distance
3. Find K Nearest Neighbors
4. Perform Majority Voting
5. Predict Flower Species

### Output

The model predicts one of:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

and displays:

* Prediction Result
* Accuracy
* Macro F1 Score
* Confusion Matrix
* Performance Metrics
